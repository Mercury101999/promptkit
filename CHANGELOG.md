# Changelog

## 1.0.0 - 2026-11-19

First release of PromptKit.

- Build a prompt from a short form, with a live preview that includes only the sections you filled in.
- Copy it in one tap, or share it when the device supports sharing.
- Start from 18 templates, including everyday writing and briefs for agents you run.
- Fill `{{placeholders}}` before a template is applied.
- Save, edit, duplicate, favorite, search, and delete your own templates.
- Keep the last 50 copied prompts on the device.
- Export and import saved templates as JSON.
- Install the web app on a phone. After the first visit it works offline.
- Light and dark themes follow the system, with a manual override.
